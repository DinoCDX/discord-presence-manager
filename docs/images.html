Images

Discord doesn't accept pictures directly. DPM uploads each image once to a Discord application that you own and refers to it by ID.

  1. Open the Discord developer portal and create a New Application. The name doesn't matter.
  2. Copy the Application ID from the General Information page.
  3. In DPM, open Settings, then Images, and paste the ID.
  4. Tap Check. The status should say Connected.
  5. Make sure Send images is on.

DPM sends the app icon, or the cover art with the app icon as a small badge. The activity line still reads like "Listening to" followed by the app name.

Without an application ID Discord shows text only, and the preview says so.
