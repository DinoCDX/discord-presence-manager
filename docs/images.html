Images

Album art, video thumbnails and static pictures are sent from public links, so they work with no setup.

Album art and thumbnails

  1. Open Settings, go to Pictures, and turn on Send pictures. It's off by default.

That's all you need. Album art and video thumbnails come from their public links, and DPM uses its own Discord application for them.

Static pictures

In the static editor, tap the Large or Small picture and paste a public https:// link. DPM sends the picture from that link, so there's nothing to upload. Pictures saved from your phone's storage aren't supported.

Pictures without a link

Some pictures don't come with a link, like cover art from a media player, and the small app icon on the card. For those, DPM uploads the picture through a Discord application of your own. This needs developer options, which are hidden until you unlock them.

  1. Unlock developer options. In Settings, open About and tap the version seven times, until DPM says developer mode is on.
  2. Open the Discord developer portal and make a New Application. Copy its Application ID from the General Information page.
  3. In Settings, under Developer, open Application for pictures. Paste the ID, optionally name it, tap Add app, then tap Check. The status line should say it's connected.
  4. Add your login token under Login token for uploads, in the same section.

Using a user token in an app breaks Discord's Terms of Service, so your account can be limited or banned. Only add the token if you accept that risk, and remove it when you no longer need uploads.

Testing

To check that pictures get through, use Test presence with an image in the Developer section. Pause presence first so DPM doesn't replace the test.

Images go with the presence. If there's no picture, the DPM icon is shown instead.
