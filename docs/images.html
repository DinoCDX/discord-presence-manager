Images

Discord won't take pictures directly. So DPM uploads each image once to a Discord application that belongs to you, then points to it by ID.

  1. Open the Discord developer portal and make a New Application. The name can be anything.
  2. Copy its Application ID from the General Information page.
  3. In DPM, go to Settings, then Images, and paste the ID in.
  4. Tap Check. It should say Connected.
  5. Make sure Send images is switched on.

What gets sent is the app's icon, or the cover art with the app icon as a small badge. The line above it still reads something like "Listening to" followed by the app name.

No application ID means Discord only shows text, and the preview in DPM will tell you so.

DPM (Discord Presence Manager) isn't affiliated with Discord. Source on GitHub
