Build

Requirements

  • JDK 17
  • Android SDK platform 34
  • Android Studio, or just the command line tools

Debug build

git clone https://github.com/DinoCDX/discord-presence-manager.git
cd discord-presence-manager
./gradlew assembleDebug

The APK ends up in app/build/outputs/apk/debug/app-debug.apk.

Releases

Pushing a tag that starts with v runs the release workflow in .github/workflows/release.yml. It builds a signed APK and attaches it to a new GitHub release. The in-app updater reads that release.

Android only installs an update over an existing app if both are signed with the same key. Create one key and keep it:

keytool -genkeypair -v -keystore dpm-release.jks -alias dpm \
  -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 dpm-release.jks

Add these repository secrets under Settings, Secrets and variables, Actions:

SecretValue
KEYSTORE_BASE64Output of the base64 command
KEYSTORE_PASSWORDThe keystore password
KEY_ALIASdpm
KEY_PASSWORDThe key password

Then tag and push:

git tag v1.0.0
git push origin v1.0.0

The tag sets the version. v1.2.3 becomes version name 1.2.3 and version code 10203. Back up the keystore somewhere safe. If you lose it, nobody can update in place any more.

Publishing these docs

In the repository settings open Pages, choose Deploy from a branch, then pick your main branch and the /docs folder.
