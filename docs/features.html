Features

Dynamic mode

Follows what you are doing. Media that is playing comes first, then the app or game on screen. Games always show. Other apps show if you allow them in the Apps tab.

Static mode

You write the activity yourself: type (Playing, Listening to, Watching, Competing in), name, details and state. The preview updates as you type and changes save on their own.

Preview

The preview card looks like the activity on Discord, with cover art, an app icon badge and a progress bar for media.

Apps

  • One switch for popular apps such as YouTube, Instagram and TikTok.
  • One switch for every other app. Anything you ignore stays hidden.
  • Each app can be set to Auto, Allowed or Ignored. Ignored apps never show, even when playing media.
  • Each app can have its own type, name, details and state.

Schedule and rules

  • Time windows pick the days and a start and end time. A window that ends before it starts runs into the next day.
  • Online only hides your presence when your status is Idle, Do Not Disturb or Invisible.
  • Pause stops sharing without turning DPM off.

Accounts

  • Add accounts by browser login, token or QR code.
  • Switching is instant and presence reconnects on the new account.
  • You can show or copy the active account's token. Removing an account only removes it from this phone.

Background

  • Runs as a foreground service with a notification.
  • Can start again after a reboot.
  • Polls less often while the screen is off, and backs off when Discord can't be reached.

Updates

DPM asks GitHub for the latest release when you open the app, at most once every 12 hours. If a newer version exists you can download it inside the app and install it. The download is checked against its size and SHA-256 hash before the install prompt appears. You can turn the automatic check off in Settings, or check by hand.
