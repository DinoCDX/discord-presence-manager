Troubleshooting

Nothing shows on Discord

Check that Share my presence is on and not paused. The line under it says what is blocking it, for example a schedule or the online-only rule. In dynamic mode the app also has to be allowed in the Apps tab and Usage access has to be granted.

Music or video isn't detected

Grant Notification access. DPM reads the media session through it. Also check that the player isn't set to Ignored.

Presence stops after a while

Allow background activity under Settings, Background. Phones from Xiaomi, Oppo, Vivo, Huawei and Samsung often have a separate autostart or app launch setting in system settings that also needs to be on.

It says Reconnecting for a long time

DPM retries with longer and longer pauses, up to a minute, while Discord or your network is unreachable. It reconnects by itself once the connection is back.

Images are missing

Add an application ID under Settings, Images, then tap Check. See Images.

Login problems

Use the Browser tab. It signs in on Discord's own page, so captchas, two-factor codes and passkeys work.

An update won't install

Android needs permission to install apps from DPM. Tap Install again and allow it when the settings page opens. If it says the app wasn't installed, the release was probably signed with a different key than the version on your phone. Uninstall DPM and install the new APK.

Wallpaper colors or the themed icon don't show

Wallpaper colors need Android 12 and the Dynamic color switch in Settings. The themed icon needs Android 13 and themed icons turned on in your launcher.
