Setup

  1. Download the APK from the latest release and install it. Android will ask you to allow installs from your browser or file manager the first time.
  2. Log in. The Browser tab uses Discord's own login page inside the app, so captchas, two-factor codes and passkeys work. Token and QR are the other options.
  3. Go through the intro and grant the permissions you want. You can skip any of them. See Permissions.
  4. On the Presence tab, turn on Share my presence.
  5. On the Apps tab, pick which apps are allowed to show up.
  6. Optional: set up images for app icons and cover art.

Tabs

TabWhat it has
PresenceThe on/off switch, pause, a live preview, dynamic or static mode, the schedule and the online-only rule.
AppsA searchable list of your apps. Allow or ignore each one and set custom text.
SettingsAccounts, theme, images, background options, updates, token and credits.

While it runs there is a notification with Pause and Stop buttons.
